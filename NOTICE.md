# Threadwave provenance

Threadwave is an independently published derivative of
[Deln0r/ygo](https://github.com/Deln0r/ygo), a pure-Go Yjs implementation
created by Ivan Chechin (Deln0r) and its contributors.

The initial source snapshot was taken from upstream commit
[`99c1062`](https://github.com/Deln0r/ygo/commit/99c1062) (after the v1.16.0
release). Threadwave was then rebranded, moved to the
`github.com/Arnavsharma2/threadwave` module path, and developed through a new,
independent Git history.

The upstream project and this derivative are distributed under the MIT
License. The original copyright notice is preserved in [LICENSE](LICENSE).
Threadwave does not claim to be the official Yjs-listed Go port; that listing
belongs to the upstream project.
